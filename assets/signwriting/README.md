# Abecedario de LSM en SignWriting

Las 27 grafías del abecedario manual se tomaron de *Lengua de Señas Mexicana, 3 de mayo de 2025*, diccionario de SignPuddle Online publicado por el Center for Sutton Movement Writing. El sistema Sutton SignWriting fue creado por Valerie Sutton.

| Letras | Páginas correspondientes |
| --- | --- |
| A, B, C, D, E, F | 5, 14, 19, 33, 38, 44 |
| G, H, I, J, K, L | 50, 53, 57, 59, 61, 61 |
| M, N, Ñ, O, P, Q | 67, 76, 139, 83, 100, 108 |
| R, S, T, U, V, W | 109, 114, 123, 128, 130, 134 |
| X, Y, Z | 136, 136, 138 |

Se recortó una variante documentada por letra y se centró en una imagen de 128 × 128 píxeles. Se conservó la disposición de sus componentes y las marcas de movimiento. Las fichas de cámara muestran las referencias de la UABCS y pueden presentar variantes distintas.
